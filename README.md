# Brendan Wovchko · Portfolio

Professional portfolio for Brendan Wovchko, CTO & Operating Board at Ramsey Solutions.
Same design system as the Executive version of maxwell-wovchko.vercel.app: editorial serif type,
loader, smooth scroll, circle cursor, magnetic buttons, masked reveals and parallax (no cursor spotlight),
recolored from the headshot: light grey, charcoal and denim.

Built with Next.js + Framer Motion. Deployed on Vercel.
